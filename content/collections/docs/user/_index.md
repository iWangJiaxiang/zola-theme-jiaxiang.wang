# jiaxiang.wang 主题用户文档

欢迎使用 jiaxiang.wang 主题！这是一个功能丰富、高度可定制的 Zola 静态网站主题。本文档将帮助您快速上手并充分利用主题的各项功能。

## 📚 文档目录

### 🚀 快速开始

1. **[工具部署](./02%20deployment.md)** - 从零开始搭建您的博客
   - Zola 安装与配置
   - 主题下载与设置
   - 本地开发环境
   - 生产环境部署

### ⚙️ 配置指南

2. **[基础配置 (config.toml)](./03%20config.md)** - Zola 核心配置
   - 站点基本信息设置
   - 构建和 URL 配置
   - Markdown 和搜索配置
   - 多语言支持设置

3. **[主题配置 (theme.toml)](./04%20theme-config.md)** - 主题特定功能
   - 外观和布局设置
   - 功能模块配置
   - 分析统计集成
   - 评论系统配置

4. **[数据配置 (data.toml)](./05%20data-config.md)** - 内容和菜单管理
   - 导航菜单设置
   - 社交媒体链接
   - 友情链接管理
   - 项目展示配置

   - 自定义样式和脚本

   - SEO 和多语言支持

## 🎯 主要特性

### 🎨 设计特色
- **现代化设计** - 简洁美观的界面设计
- **响应式布局** - 完美适配各种设备
- **暗色模式** - 支持明暗主题切换
- **多种布局** - 灵活的文章和页面布局选项

### 🚀 功能丰富
- **搜索功能** - 支持 Algolia 和 Meilisearch
- **评论系统** - 集成 Twikoo、Artalk、Waline
- **分析统计** - 支持 Umami、Clarity 等
- **社交分享** - 完整的社交媒体集成

### 🛠️ 开发友好
- **高度可定制** - 丰富的配置选项
- **性能优化** - 快速加载和 SEO 友好
- **易于扩展** - 支持自定义模板和短代码
- **文档完善** - 详细的使用说明和示例

## 💡 使用建议

### 配置优先级
1. 先完成基础的 `config.toml` 配置
2. 根据需求调整 `theme.toml` 中的功能
3. 设置 `data.toml` 中的菜单和内容
4. 最后进行个性化自定义

### 常见用途
- **个人博客** - 技术分享、生活记录
- **项目文档** - 开源项目、产品说明
- **企业官网** - 公司介绍、产品展示
- **作品集** - 设计作品、项目展示
